# EcoPegada — Hackathon: Mudanças Climáticas

## Esse é o tipo do meu projeto:
> Site (Flask)

## Aqui está a ideia do meu projeto:
> Uma calculadora de pegada de carbono: a pessoa informa seus hábitos (carro, energia, carne) e vê quanto CO₂ emite por ano, para entender como suas escolhas contribuem para as mudanças climáticas.

## As bibliotecas que vou usar:
- Flask (rotas e templates)

## Referências úteis:
- Calculadora ecológica feita nas aulas (HTML + templates Flask)

## Os artigos de orientação que me ajudarão durante o desenvolvimento
- [O que são mudanças climáticas? (ONU Brasil)](https://brasil.un.org/pt-br/175180-o-que-s%C3%A3o-mudan%C3%A7as-clim%C3%A1ticas)
- [Causas e efeitos das mudanças climáticas (ONU)](https://www.un.org/pt/climatechange/science/causes-effects-climate-change)
- [Flask — Quickstart](https://flask.palletsprojects.com/en/stable/quickstart/)

## Como rodar
```
pip install -r requirements.txt
python main.py
```
